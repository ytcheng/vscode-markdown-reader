# V0.3 Reader Implementation Plan

> **For agentic workers:** Use test-driven-development for each behavior and requesting-code-review before completion. Execute the renderer task independently while the main agent integrates settings, controls and export.

**Goal:** 实现已确认的右上角菜单、阅读设置、主题、大文件模式、打印及 HTML 导出。

**Architecture:** 共享纯设置模块负责默认值和验证；扩展宿主管理配置与渲染；ReaderControls 独立负责弹窗与消息；HtmlExporter 从可信 renderer 输出构造便携 HTML。保留现有 ReaderApp 目录和搜索流程。

**Tech Stack:** TypeScript、VS Code API、MarkdownIt、Less、Vitest、Playwright。

- [x] 1. 新增 `src/settings/ReaderSettings.ts`，定义 theme/colorMode/fontFamily/fontSize/contentMaxWidth/largeFileMode/largeFileThresholdKb；先在 `test/unit/ReaderSettings.test.ts` 验证枚举、数字边界和字体安全约束，再实现规范化与单项更新验证。
- [x] 2. 修改 `src/renderer/MarkdownRenderer.ts`、`ShikiRenderer.ts`、`types.ts`：第三参数 `{ largeFile?: boolean }`；结果 `largeFile?: boolean`；性能模式跳过语法高亮、公式、图表。测试同源文档正常与简化渲染、UTF-8 阈值和双主题语法高亮。
- [x] 3. 新增 `src/webview/ReaderControls.ts` 与 `controlsHtml.ts`；接入 `html.ts`、`ReaderApp.ts`；测试菜单开关、设置弹窗、Escape/焦点、字号/字体变更与重置消息。使用附件 SVG 原始 path。
- [x] 4. 新增 `media/settings.less`、`media/themes.less`、`media/print.less`，由 reader.less 导入；保留 Reader 浅色默认版式，支持深色、GitHub 和宿主高对比度。浏览器检查窄屏、弹窗、打印和搜索避让。
- [x] 5. 扩展 messages、security/messages 和 MarkdownEditorProvider；按资源读取配置、验证 Webview 消息、同作用域保存并广播、订阅宿主主题和配置变化，给文档 session 动态选择大文件模式。先扩展 provider mock 和消息测试。
- [x] 6. 新增 `src/export/HtmlExporter.ts`、`ExportService.ts`，从可信 Markdown 重新渲染、嵌入资源、保存 HTML 或浏览器打开打印页。测试转义、图片限制、字体嵌入、保存取消及文件错误；链接继续使用既有边界。
- [x] 7. 更新 package.json/package-lock.json 至 0.3.0、配置项、命令、中英文说明和 CHANGELOG；执行 `npm run check`、扩展测试与针对 V0.3 的浏览器检查；独立代码审查并修复问题。
