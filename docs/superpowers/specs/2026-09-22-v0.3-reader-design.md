# V0.3 阅读设置与导出设计

用户已确认参考 Chrome Markdown Reader：正文右上角固定菜单，使用用户提供的三横线 SVG；左上角保留目录。菜单含查看源码、打印、导出 HTML、阅读设置、反馈、关于。PDF 通过浏览器打印保存，不承诺原生 PDF 导出。

阅读设置使用居中原生 dialog，支持键盘关闭、焦点恢复、窄屏滚动。Reader / GitHub 为排版主题；auto / light / dark 为独立配色，高对比度优先尊重宿主。字体预设为系统、衬线、等宽和自定义本地字体；字号 12–32px；正文宽度 560–1600px。调整即时预览并保存 VS Code 配置；已有工作区覆盖时写相同作用域，否则保存到用户配置。重置只重置阅读设置。主题和字体不重新解析 Markdown。

大文件模式 auto / on / off，默认阈值 1 MiB UTF-8。开启时保留正文、目录、复制、搜索，跳过 Shiki、KaTeX 和 Mermaid 的昂贵渲染，显示源码和状态说明。通过设置可恢复完整渲染。配置变化只在性能设置变化时重新渲染文档。

打印在系统浏览器打开临时、独立 HTML，提供显式打印按钮；打印样式白底深字、隐藏控件与目录，代码自动换行、标题避免孤立分页。HTML 导出通过保存对话框，内嵌样式、本地图片和公式字体；保留外部 HTTPS 图片链接。Mermaid 导出已完成的 SVG 图片，未完成或大文件模式则保留源码并说明。安全边界：扩展重新生成正文，只接受受限的 SVG 图片 data URI 快照；原始 HTML 仍禁用，不接受任意 Webview HTML。

拆分共享设置、菜单控制器、主题样式和导出服务，避免继续扩大 ReaderApp。配置变化同步打开的阅读器；失败显示 VS Code 错误提示，取消保存不写文件。保留旧目录、搜索、源码定位行为。

验证覆盖：设置边界和消息白名单、主题/字号交互、工作区作用域、配置广播、大文件降级与恢复、导出转义与资源嵌入、键盘可用性、打印 CSS、现有单元及扩展测试。版本更新至 0.3.0，中英文 README 与 CHANGELOG 同步更新。本任务不发布 Marketplace。
