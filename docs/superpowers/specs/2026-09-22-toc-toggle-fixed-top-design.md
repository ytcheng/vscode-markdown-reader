# 目录开关固定顶部设计

## 目标

让目录开关按钮固定在 Markdown Reader Webview 视口顶部，不随正文或目录滚动而移动；宽屏和窄屏均适用。

## 方案

目录开关继续使用现有的 HTML 元素、点击处理和无障碍属性，仅调整样式定位：将 `.toc-toggle` 从相对 `.document-container` 的绝对定位改为相对 Webview 视口的 `position: fixed`，并保留固定的顶部间距。

在宽屏且目录显示时，按钮的 `left` 位置基于目录栏宽度与分隔条，为目录滚动条和拖拽条预留空间；目录隐藏时，按钮回到 Webview 左侧安全边距。窄屏沿用左侧安全边距，且不会影响已有抽屉目录的交互。

## 边界

- 不更改目录生成、显示隐藏状态、抽屉逻辑、拖拽调宽逻辑或消息协议。
- 不增加滚动事件监听或 JavaScript 定位计算。
- 仅更新受定位规则影响的样式测试。

## 验收

- 滚动正文或目录时，按钮始终停留在 Webview 视口顶部。
- 宽屏目录显示时，按钮不覆盖目录滚动条或拖拽条。
- 宽屏目录隐藏、以及所有窄屏状态下，按钮位于左侧安全边距。
- 目录开关的点击、`aria-expanded` 状态和窄屏抽屉行为不变。
- 样式编译与相关单元测试通过。
