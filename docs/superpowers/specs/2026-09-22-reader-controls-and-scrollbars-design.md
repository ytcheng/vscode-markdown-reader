# 阅读器控件与滚动条调整设计

## 目标

让 Markdown Reader 的阅读界面更接近 Chrome Markdown Reader：移除 Webview 顶部工具栏，将目录控制放在正文左上角，并统一浅色细窄的滚动条。

## 范围

- 完整删除 Webview 内的 `Edit / Contents` 顶部工具栏及其分隔线。
- 编辑器标题栏只保留“打开源码”命令，并配置 VS Code 原生 `edit` 图标。
- 从编辑器标题栏移除“显示/隐藏目录”命令。
- 在正文区域左上角新增无文字的目录图标按钮：桌面端切换左侧目录；窄屏端复用现有抽屉目录行为。
- 目录图标按钮须保留无障碍名称和 `aria-expanded` 状态；抽屉关闭后恢复该按钮焦点。
- 左侧目录文字左侧内边距收紧到约 8px；仅子目录保留表达层级所需的缩进。
- 为页面、目录和代码块等横向/纵向可滚动区域设置统一的细窄浅色滚动条，兼容 Chromium 和 Firefox。

## 不在范围内

- 不改变目录生成、层级过滤、锚点导航或 VS Code 配置项。
- 不修改正文排版、目录栏宽度或目录与正文的分隔线。

## 实现边界

`src/webview/html.ts` 负责移除工具栏并将目录切换按钮放入正文容器；`src/webview/ReaderApp.ts` 继续处理同一个按钮 ID 的桌面切换和窄屏抽屉逻辑；`media/reader.less` 负责栅格、悬浮按钮、目录内边距和滚动条样式；`package.json` 调整标题栏命令贡献。

## 验收与测试

- Webview HTML 不再包含 `reader-toolbar` 或文字按钮。
- 点击正文左上角按钮后，宽屏目录可见状态与 `aria-expanded` 同步；窄屏抽屉仍能以 Escape 关闭并恢复焦点。
- 标题栏只声明带 `edit` 图标的打开源码命令。
- 编译后的样式包含目录、页面和代码块滚动条的细窄浅色规则，并包含收紧后的目录内边距。
- 运行类型检查、单元测试和构建验证。
