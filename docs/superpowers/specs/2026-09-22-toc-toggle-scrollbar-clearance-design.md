# 目录开关、目录宽度与代码底色设计

## 目标

让目录开关在宽屏阅读器中始终位于正文栏左上方，不覆盖左侧目录的滚动条或分隔线；目录隐藏后仍保持同一正文侧的安全边距。目录宽度可拖拽并在重新打开文档后恢复，同时提高代码区域的视觉区分度。

## 根因

现有 `.toc-toggle` 使用相对 Webview 的 `position: fixed`，展开目录时以目录宽度作为其左侧坐标。按钮因此跨越目录栏的右边缘，覆盖该栏的滚动条轨道。

## 设计

`.document-container` 成为定位上下文。目录按钮改为相对该容器的绝对定位，`left` 固定为 `24px`、`top` 固定为 `12px`，并移除边框和背景；仅保留颜色变化和键盘焦点轮廓。由于 CSS Grid 在目录展开/收起时会重新放置正文容器，按钮会随正文栏一起移动：展开时在目录右边界之外，收起时在 Webview 左侧正文安全边距内。

宽屏目录和正文之间新增语义化 `role="separator"` 的拖拽条。Webview 在指针拖动期间更新 `--reader-toc-width`，在松开指针时发送一个经过范围校验的宽度消息。扩展将该值写入现有的 `markdownReader.toc.width` 工作区配置；每个 Webview 就绪时读取该配置并发送布局消息，因此关闭、重开或重新加载文档后宽度不丢失。窄屏不显示拖拽条，抽屉继续使用既有键盘和焦点逻辑。

目录内边距从 8px 缩至 4px。预格式化代码块与行内代码分别改用对比更明显的浅蓝灰色背景，文字仍保持深色并满足阅读需求。

## 验收

- 编译 CSS 中 `.document-container` 建立定位上下文。
- `.toc-toggle` 使用 `position: absolute` 和 `left: 24px`，无边框、无背景，不再使用目录宽度计算或 `position: fixed`。
- 宽屏目录显示和隐藏时，按钮均不会覆盖目录滚动条。
- 宽屏拖动分隔条时目录宽度在 180--480px 范围内变化；松开后写入 `markdownReader.toc.width`，重新打开文档后恢复。
- 目录左侧内边距为 4px；代码块和行内代码使用更明显的浅蓝灰色背景。
- 现有样式、类型检查和单元测试通过。
