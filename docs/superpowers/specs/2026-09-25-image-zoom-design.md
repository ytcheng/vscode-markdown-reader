# 图片放大浮层设计

## 目标

让读者可以在 Markdown 预览中点击 Mermaid 图或独立图片，在浮层中查看清晰的大图，并按需放大或缩小。

## 交互

- 已渲染的 Mermaid 图和未链接的 Markdown 图片提供可聚焦的打开入口。点击图表或图片，或聚焦后按 Enter / Space 打开浮层。包含在链接中的图片保留原有链接行为。
- 浮层没有标题栏；右上角只放关闭按钮，底部中央依次放缩小、缩放比例、放大和恢复适配控件。
- 浮层铺满 VS Code 预览区域，不显示边框、圆角或阴影。
- 放大和缩小控件使用带加号、减号的放大镜图标；恢复适配控件使用适配视图图标。按钮保持透明且无边框。
- 图形初始适配窗口；缩放只改变浮层中的图形。图形超出可视区域时，用户可以拖动图形平移查看其他区域，也可以通过浮层内的滚动条查看。
- 关闭按钮、按 Escape 或点击浮层遮罩关闭浮层。关闭后焦点返回打开浮层的图表。
- 中英文界面均提供对应的控件名称和无障碍标签。

## 实现设计

- `MermaidRenderer` 继续将 Mermaid SVG 渲染为现有的 `img.mermaid-diagram`。`ReaderApp` 为独立的 Markdown 图片增加可聚焦、可键盘操作的打开语义。
- `ReaderApp` 负责打开和关闭模态浮层、缩放比例、键盘交互以及关闭后的焦点恢复。浮层复用原图的 URL，不重新调用 Mermaid 渲染器。
- 浮层通过 DOM API 创建，使用原生 `<dialog>` 的模态行为；控件图标由 SVG DOM 节点绘制，缩放只作用于浮层中的图片，不改变正文图表的尺寸。
- `localization.ts` 增加中文和英文的控件文案。`media/reader.less` 增加浮层、工具栏和可滚动图像区域的样式，并使用 VS Code 主题变量适配深色及高对比度主题。
- `npm run build` 负责生成随扩展提供的 `media/reader.js` 和 `media/reader.css`，不直接编辑生成文件。

## 无障碍与安全

- 图表打开入口使用键盘可达的语义和本地化无障碍名称。
- 对话框有可访问名称，缩放和关闭按钮有明确标签；缩放比例使用礼貌播报的状态区域。
- 使用现有图片 URL，不将 Mermaid SVG 字符串插入活动 DOM，也不增加运行时依赖。
- 模态打开期间将键盘焦点限制在对话框；关闭时恢复到原图入口。

## 验收条件

- 点击 Mermaid 图或独立 Markdown 图片可打开浮层，初始视图完整适配当前可用窗口区域；链接中的图片仍可导航到原链接。
- 放大、缩小和恢复适配控件可更新图形尺寸及缩放比例；正文中的图保持原尺寸。
- 放大后可以通过滚动查看图形各区域；关闭按钮、Escape 和点击遮罩都能关闭浮层。
- 键盘用户可打开、操作和关闭浮层，关闭后焦点回到触发图表。
- 中英文控件文案正确，深色和高对比度主题下浮层仍可辨识。
